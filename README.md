# 💻 Dé-codées – API Backend Flask

**Dé-codées** est une API backend développée avec **Flask (architecture MVC)** dans le cadre de ma formation Python Fullstack.

Le projet vise à accompagner les **femmes en reconversion vers les métiers du numérique**, en leur offrant une plateforme pour :

- Documenter leur parcours de formation
- Identifier leurs compétences (soft & hard skills)
- Organiser et visualiser leurs ressources utiles
- Partager un témoignage inspirant

---

## 🧱 Technologies utilisées

- Python 3.11
- Flask 3.x
- Flask-RESTful
- SQLAlchemy
- Marshmallow
- PostgreSQL
- Thunder Client (tests API dans VS Code)
